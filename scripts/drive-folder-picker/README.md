# 완성본 Drive 폴더 최초 연결 — Windows

기존 `YOUTUBE_REFRESH_TOKEN`은 유지합니다. 이 도구는 별도 Drive 계정에 `drive.file`만 요청하고, Google Picker에서 기존 완성본 폴더를 선택하게 합니다. 이 선택이 앱에 해당 폴더 접근을 부여합니다. 매 영상마다 선택할 필요는 없습니다. 접근을 취소하거나 OAuth 프로젝트를 변경하면 다시 연결해야 할 수 있습니다.

## Google Cloud 준비 (기존 OAuth와 같은 프로젝트)

1. Google Drive API와 **Google Picker API**를 사용 설정합니다.
2. Google Auth Platform → 데이터 액세스에 `https://www.googleapis.com/auth/drive.file`을 추가합니다. 테스트 앱이면 Drive 소유 계정을 테스트 사용자에 추가합니다.
3. API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → **API 키**를 생성합니다. OAuth 클라이언트 ID/클라이언트 시크릿과는 다릅니다. API 제한은 **Google Picker API만** 허용합니다. 웹사이트 제한은 로컬 선택 창에 맞게 `http://127.0.0.1:*/*`로 설정합니다. 콘솔에서 로컬 주소/와일드카드 입력이 거부되면 제한을 무작정 해제하지 말고 해당 화면을 확인합니다. 이 키는 브라우저에서 쓰는 키이며 토큰/시크릿을 넣으면 안 됩니다.
4. 프로젝트 설정에서 숫자로 된 **프로젝트 번호**를 확인합니다. 문자 프로젝트 ID가 아닙니다.
5. 이전에 다운로드한 **데스크톱 앱용 OAuth 클라이언트 JSON**을 준비합니다. 기존 토큰 결과 JSON과 다릅니다. YouTube 인증에 쓴 것과 같은 클라이언트를 사용합니다. 다른 클라이언트를 사용했다면 클라우드에서도 그에 맞는 Drive 전용 클라이언트 ID·시크릿이 필요합니다.

## 실행

ZIP을 새 폴더에 완전히 압축 해제하고 `드라이브 연결 시작.cmd`를 더블 클릭합니다. Python 3.10 이상과 인터넷이 필요합니다.

1. 파일 선택 창에서 데스크톱 OAuth 클라이언트 JSON을 선택합니다.
2. 같은 프로젝트의 Picker API 키와 숫자 프로젝트 번호를 입력합니다.
3. 브라우저에서 **Drive 폴더 소유 계정**으로 로그인하고 Drive 접근을 허용합니다. 실행 창을 닫지 않습니다.
4. 이어서 열리는 페이지에서 `폴더 선택` → 기존 **Tictoc** 폴더를 선택합니다. 대상 ID는 `1jw6LWt911brvCq6oNBJOZJHW1ZNV1pIO`입니다. 다른 폴더는 거부합니다.
5. 앱이 Google Drive API로 실제 폴더 접근과 `canAddChildren` 권한을 확인합니다. 이 도구 자체는 영상이나 테스트 파일을 업로드하지 않습니다.
6. 성공 시 `%USERPROFILE%\Codex-Drive-Auth\날짜-시간` 폴더가 열립니다. `GOOGLE_DRIVE_REFRESH_TOKEN.txt` 내용을 같은 이름의 Codex 네트워크 시크릿 값에 교체합니다. 허용 도메인은 `oauth2.googleapis.com`입니다. 저장 후 환경을 게시합니다. **`YOUTUBE_REFRESH_TOKEN`은 수정하지 않습니다.**
7. 채팅에 “폴더 연결 및 새 토큰 등록 완료”라고 알려줍니다. 클라우드에서 실제 접근을 다시 검증하고 기존 EP108·EP109 최종본 업로드를 재개할 수 있습니다.

토큰 파일과 클라이언트 JSON을 채팅·GitHub·Drive 공개 폴더에 올리지 마세요. 도구는 이 파일들을 코드 폴더에 저장하거나 유튜브 인증 파일을 덮어쓰지 않습니다. OAuth 액세스 토큰은 실행 중인 로컬 프로세스와 Google Picker에만 전달하고 서버 로그에 기록하지 않습니다. 프로그램 종료 후 임시 액세스 토큰을 파일로 남기지 않습니다.

## 검증 범위

클라우드에서 로컬 선택 서버의 잘못된 Host/Origin 차단, 잘못된 폴더/읽기 전용 폴더 거부, 토큰 응답 경로 및 보안 헤더를 자동 검사했습니다. 실제 Windows 브라우저 로그인과 Picker 승인은 사용자 컴퓨터에서 완료해야 합니다. Cloud Console 설정과 브라우저 API 키 제한의 실제 적용도 그때 확인합니다.
